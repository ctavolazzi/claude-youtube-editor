# fonts (beeplumb-explainer)

Latin subsets of two Google Fonts, bundled locally so the shot renders with no network
font fetch. Both are licensed under the SIL Open Font License 1.1.

- `VT323-400.woff2` (VT323, by Peter Hull)
- `CourierPrime-400.woff2`, `CourierPrime-700.woff2` (Courier Prime, by Alan Dague-Greene)
